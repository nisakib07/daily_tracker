Flutter App Progress Notes
Date: July 7, 2026

Project goal
------------
We are converting the existing Money Master website into a Flutter app inside the same project folder.
The Flutter app lives in the mobile/ folder and uses the same Supabase backend as the web version.

The goal is not just to show the website inside an app. We are rebuilding the main app experience in Flutter:
authentication, dashboard, accounts, transactions, ledger, budgets, investments, analytics, and settings.


Current setup
-------------
- Flutter project created inside mobile/
- Supabase environment values are wired into the Flutter dev runner
- Windows Developer Mode was enabled so Flutter plugins can work correctly
- Local preview runs on:
  http://127.0.0.1:52710
- The preview is started without opening a new browser window automatically
- The app is currently forced to light mode to avoid confusing dark-mode form rendering

Current known issue / latest work
---------------------------------
The main issue we were debugging is the transaction form.

What happened:
- When clicking Money In, Money Out, or Transfer, the form area appeared blank.
- The console showed Flutter rendering/layout assertions.
- The exact console error later showed the problem was inside the account dropdown:
  RenderFlex children have non-zero flex but incoming width constraints are unbounded.

Latest fix made:
- Transaction forms now open as a normal full-screen form page instead of a modal bottom sheet.
- The unsafe Row + Expanded layout inside account dropdown items was removed.
- Dropdowns now use isExpanded: true.
